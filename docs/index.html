    03

    How it works

    varuna fact checker reads the whole reel, splits it into claims, and checks each one in three tiers of sources.

    1. 1

      Read the reel

      Speech is transcribed, on-screen text is read from frames, and the caption is added.

    2. 2

      Split into claims

      Each checkable statement is separated. Opinions and predictions are marked, not judged.

    3. 3

      Check in three tiers

      Official records first, then existing fact-checks, then ranked news and web sources.

    4. 4

      Publish with an expiry

      Every result shows its sources and has a re-check date, because facts change.
